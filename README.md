# pbltogui

Conversion of the GMINE jewellery ERP from PowerBuilder to Python / PySide6.

| Folder | What it is |
|---|---|
| **`supergold/`** | **The deliverable.** The complete converted application in one self-contained folder — double-click `supergold\run.bat` to run it, `build_exe.bat` to build `SuperGold.exe`. No PowerBuilder export needed. |
| `pbl/` | The working tree: the same application plus the original PowerBuilder export (`gmine*` folders), used to re-generate `supergold/data` and to check conversions against the original source. |

Start here: [`supergold/README.md`](supergold/README.md).
